# Audio Profiles and Dialog NVDA Switch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add three named profiles (speaker, microphone, NVDA output), each activated by its own gesture. Also make the quick dialog's NVDA field switch NVDA speech at once.

**Architecture:**
- The pure profile logic goes in a new `profiles.py`. It resolves stored values to actions and builds the "save current" values. It has no NVDA imports, so `run_tests.py` can load it outside NVDA.
- `__init__.py` adds the config keys, the three scripts, the settings-panel section, and the dialog change. It reuses `setDefaultDevice`, `safeSetNvdaOutputDevice`, `findMatchingDeviceId`, `buildDeviceChoices`, and `provideFeedback`.

**Tech Stack:** Python 3 (NVDA 2025.1+), wxPython, ctypes Core Audio (`core_audio.py`), SCons add-on template.

**Spec:** `docs/superpowers/specs/2026-11-03-profiles-design.md`

## Global Constraints

- Version `2026.5`. Minimum NVDA `2025.1`, unchanged.
- No new dependencies. No `pycaw`, no `comtypes`.
- Every function is 20 lines or fewer, which is the existing project rule.
- Flat config keys: `profile{n}Name`, `profile{n}Speaker`, `profile{n}Mic`, and `profile{n}Nvda`, for n = 1 to 3. All are `string(default="")`.
  - `""` means "No change".
  - Device values use the `id|name` format.
  - `profile{n}Nvda` may also be `"default"`.
- An empty name falls back to `Profile {n}`.
- Apply order: speaker, then microphone, then NVDA output.
- Activation speaks the profile name only. Missing devices are reported as `Not connected: <names>`.
- Every new user string is wrapped in `_()` and has a translator comment.
- Before each commit, run `ruff check --fix`, then `black`, then `flake8 --max-line-length 88` on the changed `.py` files.
- Work on branch `feat/profiles`. Do not merge into `master` until Kamal confirms it works in his installed NVDA.
- "Commit" means a local commit only. Do not push.

## Review Focus

1. **NVDA already on the profile's target device:** skip the synth reload, so that speech is not cut for nothing. Test: Task 2, step 4, live check A.
2. **Saved device renamed by Windows but with the same ID:** it still matches by ID. Test: `test_resolve_matches_by_id_after_rename`, Task 1.
3. **Old name-only config value, with no `|`:** it is matched by name and not treated as missing. Test: `test_resolve_name_only_value`, Task 1.
4. **Cancel in settings after "Save current devices" or after switching the chooser:** nothing is written. Test: Task 3, live check C.
5. **Clearing the dialog's NVDA field while NVDA is on the system default:** no switch and no synth reload. Test: Task 4, live check D.

### Task 1: Pure profile logic

**Files:**
- Create: `addon/globalPlugins/audio_switcher/profiles.py`
- Create: `run_tests.py` (project root)

**Interfaces:**
- Produces:
  - `PROFILE_COUNT = 3`
  - `FIELDS = ("Name", "Speaker", "Mic", "Nvda")`
  - `profileKey(n: int, field: str) -> str`. Example: `profileKey(1, "Mic")` returns `"profile1Mic"`.
  - `profileConfspec() -> str`. It returns the twelve `key = string(default="")` lines, joined by `\n`.
  - `Resolution` (a `NamedTuple`) with these fields:
    - `speakerId: str | None`. `None` means no change.
    - `micId: str | None`
    - `nvdaId: str | None`. The value is `"default"`, a device ID, or `None`.
    - `missing: list[str]`. These are display names.
    - `isEmpty: bool`
  - `resolveProfile(values: dict, playback: list, capture: list, match) -> Resolution`
    - `values` has the keys `"Speaker"`, `"Mic"`, and `"Nvda"`. Each holds a raw config string.
    - `playback` and `capture` are lists of `(id, name)` from `getActiveDevices`.
    - `match(active, configValue) -> str | None` is injected by `__init__.py`. It wraps `parseDeviceConfig` and `findMatchingDeviceId`.
  - `currentDevicesAsProfile(speaker, mic, nvdaOutputId, playback) -> dict`
    - `speaker` and `mic` are `(id, name)` or `None`, from `getDefaultDeviceInfo`.
    - The result has the keys `"Speaker"`, `"Mic"`, and `"Nvda"`.
    - `nvdaOutputId` `"default"` (or empty) becomes `"default"`.
    - A known ID becomes `id|name`, with the name looked up in `playback`.
    - An unknown ID becomes `id|`.
  - `missingName(value: str) -> str`. It returns the name part, or the ID when the name is empty.

- [ ] **Step 1: Write the failing tests in `run_tests.py`.**
  - Load `profiles.py` with `importlib.util.spec_from_file_location` from its path, so that the package `__init__.py` (which imports wx) never runs.
  - Use plain `assert` statements and a tiny runner. The runner calls every `test_*` function, prints PASS or FAIL for each, and exits non-zero if any test fails.
  - The fake `match` is defined in the test file. It does ID equality first, then an exact name match.

```python
PLAY = [("{s1}", "Jabra"), ("{s2}", "Realtek")]
CAP = [("{m1}", "Jabra Mic")]

def test_resolve_all_connected():
    r = resolve({"Speaker": "{s1}|Jabra", "Mic": "{m1}|Jabra Mic", "Nvda": "{s2}|Realtek"})
    assert (r.speakerId, r.micId, r.nvdaId, r.missing, r.isEmpty) == ("{s1}", "{m1}", "{s2}", [], False)

def test_resolve_missing_device_named():
    r = resolve({"Speaker": "{gone}|USB Speaker", "Mic": "", "Nvda": ""})
    assert r.speakerId is None and r.missing == ["USB Speaker"] and not r.isEmpty

def test_resolve_empty_profile():
    assert resolve({"Speaker": "", "Mic": "", "Nvda": ""}).isEmpty

def test_resolve_nvda_default_needs_no_match():
    assert resolve({"Speaker": "", "Mic": "", "Nvda": "default"}).nvdaId == "default"

def test_resolve_matches_by_id_after_rename():
    assert resolve({"Speaker": "{s1}|Old Name", "Mic": "", "Nvda": ""}).speakerId == "{s1}"

def test_resolve_name_only_value():
    assert resolve({"Speaker": "Realtek", "Mic": "", "Nvda": ""}).speakerId == "{s2}"

def test_missing_name_falls_back_to_id():
    assert profiles.missingName("{x}|") == "{x}"

def test_current_devices_nvda_default():
    d = profiles.currentDevicesAsProfile(("{s1}", "Jabra"), None, "default", PLAY)
    assert d == {"Speaker": "{s1}|Jabra", "Mic": "", "Nvda": "default"}

def test_current_devices_nvda_known_and_unknown():
    assert profiles.currentDevicesAsProfile(None, None, "{s2}", PLAY)["Nvda"] == "{s2}|Realtek"
    assert profiles.currentDevicesAsProfile(None, None, "{zz}", PLAY)["Nvda"] == "{zz}|"

def test_confspec_has_twelve_keys():
    lines = profiles.profileConfspec().splitlines()
    assert len(lines) == 12 and lines[0] == 'profile1Name = string(default="")'
```

  Here `resolve(values)` is a test helper: `profiles.resolveProfile(values, PLAY, CAP, fakeMatch)`.

**Interfaces:**

- [ ] **Step 1: Change `_applySecondaryDevice`.** It keeps saving `nvdaSecondaryOutput` as it does today, and adds the following:
  - **Device value:** match it against `getActiveDevices(render=True)`.
    - If no device matches, append `_("NVDA secondary device not connected")` to `failure`, and do not switch.
    - Otherwise, if the matched ID differs from the current output, call `safeSetNvdaOutputDevice`. On success, append `_("NVDA: {device}")`. On failure, append `_("Failed to switch NVDA audio output")`.
  - **`""` (None, Clear):** read the old secondary ID before overwriting it. If the current NVDA output equals the old secondary ID, switch to `"default"`. Otherwise, do not switch (Review Focus 5).
  - **`None` (Do not change):** do nothing.
