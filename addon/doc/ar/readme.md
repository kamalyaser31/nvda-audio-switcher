# مبدل أجهزة الصوت (Audio Switcher)

• المؤلف: كمال ياسر (Kamal Yaser)
• الإصدار: 2026.1
• التوافقية: NVDA 2024.1 فما فوق

إضافة "مبدل أجهزة الصوت" هي أداة مساعدة لبرنامج NVDA تتيح تعيين أجهزة الصوت المهيأة في نظام ويندوز كأجهزة افتراضية بسرعة وسلاسة. صُممت الإضافة لتكون خفيفة وبسيطة، متجنبةً تعقيدات إضافات التحكم في الصوت الأخرى بالتركيز الحصري على تبديل الأجهزة الافتراضية بموثوقية وسرعة.

## المميزات

- تعيين أحد أجهزة مكبرات الصوت/المخرجات الثلاثة كجهاز افتراضي.
- تعيين أحد أجهزة الميكروفون/المدخلات الثلاثة كجهاز افتراضي.
- نطق اسم مكبر الصوت الافتراضي الحالي.
- نطق اسم الميكروفون الافتراضي الحالي.
- خيارات مرنة للتنبيه عند التبديل: نغمة ونطق، أو نطق فقط، أو نغمة فقط، أو بلا تنبيه.
- المطابقة بالمعرف الفريد للعتاد (Unique Hardware ID) لمنع التداخل بين الأجهزة ذات الأسماء المتطابقة.
- الاحتفاظ بالأجهزة المهيأة غير المتصلة وعرضها بوسم `(غير متصل)` في لوحة الخيارات.

## الإعدادات

افتح خيارات NVDA واختر **مبدل أجهزة الصوت (Audio Switcher)**.

الخيارات المتاحة للتهيئة:

- مكبر الصوت 1
- مكبر الصوت 2
- مكبر الصوت 3
- الميكروفون 1
- الميكروفون 2
- الميكروفون 3
- نوع التغذية الراجعة (تنبيه التبديل)

تستخدم الإضافة أسماء الأجهزة كما يعرضها نظام ويندوز. وإذا كان الجهاز غير متصل، ستصدر الإضافة تنبيهاً بنص `غير موجود` عند محاولة التبديل إليه.

## إيماءات الإدخال (Input Gestures)

يمكنك تعيين اختصارات لهذه العمليات من حوار **إيماءات الإدخال** لبرنامج NVDA.

العمليات المتاحة:

- تعيين مكبر الصوت 1 كافتراضي
- تعيين مكبر الصوت 2 كافتراضي
- تعيين مكبر الصوت 3 كافتراضي
- تعيين الميكروفون 1 كافتراضي
- تعيين الميكروفون 2 كافتراضي
- تعيين الميكروفون 3 كافتراضي
- نطق مكبر الصوت الافتراضي الحالي
- نطق الميكروفون الافتراضي الحالي
